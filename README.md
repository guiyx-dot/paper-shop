# 会员积分商城演示

给老板看的静态 H5 演示，无后端。首次必须领取积分后才能进入商城。

## 在线演示

- 用户端：https://guiyx-dot.github.io/paper-shop/
- 商户后台：https://guiyx-dot.github.io/paper-shop/#/admin

积分状态存在打开者自己的浏览器里，互不影响。

## 本地运行

```bash
npm install
npm run dev
```

浏览器会打开 `http://127.0.0.1:5174/`。电脑端是手机外框预览，手机浏览器则全屏。

「我的」页底部有「重置演示数据」，可从头再走一遍领取与兑换。
